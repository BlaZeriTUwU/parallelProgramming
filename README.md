# Лабораторная работа №4

Мной были проведены испытания технологии CUDA. Был проведен ряд экспериментов. Все вычисленные матрицы прошли проверку на правильность перемножения. Результаты умножения и исходные матрицы лежат в папке result. Тестирование производилось на разных размерах матриц и с различными конфигурациями сетки блоков. Результаты тестов представлены в таблице (значения времени представлены в секундах):

| Размер матрицы |   8×8    |  16×16   |  32×32   |
| :------------: | :------: | :------: | :------: |
|    200×200     | 0.000279 | 0.000267 | 0.000262 |
|    400×400     | 0.001069 | 0.000781 | 0.000717 |
|    800×800     | 0.008908 | 0.005958 | 0.004283 |
|   1200×1200    | 0.023950 | 0.015789 | 0.014059 |
|   1600×1600    | 0.073040 | 0.045766 | 0.032155 |
|   2000×2000    | 0.127750 | 0.073741 | 0.063503 |

Вывод: Использование CUDA позволило значительно ускорить умножение матриц. Среди протестированных конфигураций сетки блоков наилучшие результаты показал размер блока 32×32: он стабильно опережает 16×16 и 8×8 на всех размерах матриц. Это объясняется лучшим использованием потоков GPU — блок 32×32 содержит 1024 потока, что соответствует максимально допустимому количеству потоков на блок и обеспечивает более высокую загрузку вычислительных ядер. Блок 8×8 (64 потока) показывает наихудшие результаты.
